# Mnhja Loco — Tattoo Studio Website

Энэ бол Mnhja Loco tattoo studio-ийн website mockup.

## GitHub Pages дээр байршуулах
1. Энэ repo-гийн Settings > Pages руу орно
2. Source: `main` branch, `/ (root)` folder сонгоод Save дарна
3. 1-2 минутын дараа `https://<таны-нэр>.github.io/<repo-нэр>/` линк дээр амьд харагдана
